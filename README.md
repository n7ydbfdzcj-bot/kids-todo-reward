# 🐣 우리집 할일 캐시

> **바로 쓰기:** https://n7ydbfdzcj-bot.github.io/kids-todo-reward/
> 아이폰 사파리에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 전체 화면으로 열립니다.

아이와 부모가 **두 아이폰**에서 함께 쓰는 할 일 체크 · 현금 보상 웹앱입니다.
아이가 할 일을 끝내면 "완료 요청"을 보내고, 부모가 확인하면 캐시가 쌓입니다.
쌓인 캐시는 아이가 "현금 교환 신청"을 하고, 부모가 현금을 주면 잔액에서 빠집니다.
한 할 일의 기본 보상은 **300원**이고, 할 일마다 금액을 바꿀 수 있어요.

- 설치 파일이나 빌드가 필요 없는 **정적 웹앱** (HTML · CSS · JS만)
- 아이폰 사파리에서 **홈 화면에 추가**하면 앱처럼 전체 화면으로 열립니다
- 포근한 파스텔 배경(구름·별·하트 무늬)과 큼직한 카드로 아이도 쓰기 쉽게 만들었어요

## 화면 소개

| 모드 | 화면 | 하는 일 |
| --- | --- | --- |
| 아이 | 오늘 | 오늘의 할 일을 보고 ✓ 를 눌러 **완료 요청**, 지금 모은 캐시 확인, **현금 교환 신청** |
| 아이 | 기록 | 적립 · 확인 대기 · 현금 교환 내역을 날짜별로 확인 |
| 부모 | 확인 | 아이가 보낸 완료 요청을 **확인 · 300원 적립** 또는 **다시 하기**로 돌려보내기 (모두 확인도 가능) |
| 부모 | 할 일 | 할 일 추가/수정/삭제, 매일 · 요일별 · 한 번만 반복 설정, 잠시 쉬기 |
| 부모 | 현금 | 교환 신청을 **현금 지급 완료**로 바꾸기(잔액 차감), 지급 기록, 잔액 직접 조정 |
| 부모 | 설정 | 아이 이름, 기본 보상 금액, 부모 비밀번호(4자리), 두 아이폰 연결(Firebase), 전체 초기화 |

부모 모드는 **4자리 비밀번호**로 들어갑니다. 처음 값은 `0000`이고 설정에서 바꿀 수 있어요.

## 1) 바로 미리 보기

빈 폴더에서 서비스 워커까지 확인하려면 로컬 서버로 여는 게 좋아요.

```bash
cd kids-todo-reward
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 두 번 눌러 열어도 동작합니다(인터넷 주소가 아니라 일부 기능만 제한).
처음 열면 **로컬 저장 모드**로 시작하고, 예시 할 일 5개가 들어 있어요.
지우고 내 할 일로 바꾸면 됩니다.

## 2) GitHub Pages에 올리기

1. GitHub에 새 저장소를 만듭니다(공개 저장소면 무료, 이름 예: `kids-todo-reward`).
2. 이 폴더의 파일을 모두 저장소에 올립니다(`README.md`까지 같이).
3. 저장소 → **Settings → Pages** → Source를 `Deploy from a branch`, Branch를 `main / (root)`로 저장.
4. 1~2분 뒤 `https://아이디.github.io/kids-todo-reward/` 주소로 열립니다.

> 아이폰이 같은 와이파이에 있으면 집 안에서만 쓰도록 로컬 서버 주소로도 쓸 수 있지만,
> 밖에서도 쓰려면 위처럼 인터넷에 올려 두는 편이 편해요.

## 3) 두 아이폰에 앱처럼 설치

부모님 폰과 아이의 **아이폰 11 프로**에서 같은 주소를 엽니다.

1. 사파리로 주소를 엽니다. (크롬이 아니라 **사파리**여야 해요)
2. 아래쪽 **공유 버튼**(□↑) → **홈 화면에 추가**.
3. 홈 화면의 **할일캐시** 아이콘을 누르면 주소창 없이 앱처럼 열립니다.

## 4) 두 아이폰 실시간 연결 (Firebase, 무료)

연결하지 않으면 각 폰에 따로 저장됩니다. 두 폰을 맞추려면 Firebase Realtime Database를 씁니다.
무료(Spark) 요금제로 충분합니다.

1. [console.firebase.google.com](https://console.firebase.google.com) → **프로젝트 추가**.
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기** → 위치 선택 → **테스트 모드**로 시작.
3. 만들어진 주소를 복사합니다. 예: `https://my-family-default-rtdb.firebaseio.com`
4. **규칙(Rules)** 탭에서 아래처럼 저장합니다.

```json
{
  "rules": {
    "families": {
      "$room": { ".read": true, ".write": true }
    }
  }
}
```

5. 두 폰 모두 앱 → **부모 모드 → 설정 → 두 아이폰 연결**에서
   - **Realtime Database 주소**: 위에서 복사한 주소
   - **가족 방 코드**: 두 폰에 똑같이 넣을 임의의 코드 (예: `uri-family-7th`)
   를 넣고 **연결하기**를 누릅니다.
6. 화면 위쪽에 **실시간 연결** 표시가 뜨면 성공! 3초마다 서로 맞춰집니다.

### 꼭 알아두세요 (보안)

- 위 규칙은 **주소와 방 코드를 아는 사람이면 읽고 쓸 수 있는** 설정입니다.
  가족용으로는 충분하지만, 방 코드는 남에게 알려주지 말고 추측하기 어렵게 정하세요.
- 더 안전하게 쓰려면 Firebase **Authentication → 익명 로그인**을 켜고 규칙에 `auth != null`을
  추가하는 방법이 있습니다. (이 앱은 로그인 없이 쓰도록 만들었어요.)
- Firebase 주소와 방 코드는 각 폰의 브라우저 저장소에만 저장되고, 앱 파일에는 들어 있지 않습니다.
- 부모 비밀번호는 **이 기기 안에서만 확인하는 잠금**입니다. 서버에 암호화되어 저장되는 계정
  비밀번호가 아니므로, 다른 사람이 폰을 들여다보는 상황을 막는 용도로만 쓰세요.

## 5) 쓰는 방법

**아이**
- 오늘의 할 일에서 ✓ → "확인 요청 보내기". 부모님이 확인하면 초록색 **+300원** 표시로 바뀝니다.
- 캐시가 모이면 **현금 교환 신청**에서 금액을 정해 보냅니다. (전액 · 1,000원 · 3,000원 등 빠른 선택)
- **기록** 화면에서 그동안 모은 캐시와 받은 현금을 볼 수 있어요.

**부모**
- 부모 모드 진입 → 비밀번호 4자리.
- **확인** 화면에서 `확인 · 300원 적립` 또는 `다시 하기`(전할 말을 함께 적을 수 있어요).
- 잘못 적립했으면 오늘 적립 목록에서 **되돌리기**.
- **할 일** 화면에서 새 할 일 추가. 반복은 `매일` / `요일 정하기`(월·수·금 등) / `한 번만`(날짜).
- **현금** 화면에서 아이 신청을 보고 실제로 현금을 준 뒤 **현금 지급 완료**를 누르면 잔액에서 빠집니다.
- 잔액은 `적립 합계 − 지급 합계 + 직접 조정`으로 자동 계산됩니다.

## 6) 데이터 · 초기화

- 모든 기록은 쓰는 기기의 **브라우저 저장소(localStorage)** 에 저장되고, Firebase를 연결하면
  같은 방을 쓰는 기기와 맞춰집니다.
- **설정 → 모든 데이터 지우고 처음부터**: 그 기기의 기록을 지우고 처음 예시 상태로 돌립니다.
  (연결된 경우 다른 폰 기록도 다음 동기화 때 지워질 수 있으니 주의하세요.)
- **비밀번호를 잊었을 때**: 부모 모드 비밀번호 화면 아래 "비밀번호를 잊으셨나요?" → `0000`으로 되돌리기.
  기록은 그대로 남습니다.

## 7) 색 · 문구 바꾸기

`styles.css` 맨 위 `:root`의 색만 바꾸면 분위기가 바뀝니다.

```css
--pink: #ff9fc0;      /* 포인트 분홍 */
--sky: #cfe9ff;       /* 하늘색 */
--butter: #ffe9a8;    /* 노란색 */
--ink: #55453f;       /* 글자색 (진한 갈색) */
```

`app.js` 맨 위 `EMOJI_CHOICES`에 아이가 좋아하는 그림을 추가할 수 있고,
`index.html`의 `apple-mobile-web-app-title` 값으로 홈 화면 이름을 바꿀 수 있습니다.

## 알려진 한계

- 두 폰이 거의 동시에 고치면 **나중에 저장된 쪽이 남습니다**(가족 규모에서는 드문 일이에요).
- 할 일을 지워도 지난 적립 기록은 남습니다(캐시는 사라지지 않아요).
- 알림은 보내지 않습니다. 아이가 확인을 기다리는지는 앱을 열었을 때 보입니다.
